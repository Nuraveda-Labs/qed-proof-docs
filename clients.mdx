---
title: SDKs and tools
description: Choose a QED Proof client for Python, TypeScript, the terminal, or an MCP-compatible agent.
---

Install a published client to send claims and check receipts. The Python and TypeScript SDKs work in your application;
the CLI works from a terminal; the MCP server exposes QED Proof tools to an MCP client.

<CardGroup cols={2}>
  <Card title="Python SDK" icon="code" href="/sdks/python">
    Submit claims, wait for verdicts, and verify receipts from Python 3.11 or later.
  </Card>
  <Card title="TypeScript SDK" icon="code" href="/sdks/typescript">
    Use Node.js 18 or later, Deno, or a browser to submit claims and verify receipts.
  </Card>
  <Card title="CLI" icon="terminal" href="/cli">
    Submit and inspect claims, watch for verdicts, and verify a receipt from your terminal.
  </Card>
  <Card title="MCP server" icon="robot" href="/mcp-server">
    Connect an MCP client over local stdio or the hosted Streamable HTTP endpoint.
  </Card>
</CardGroup>

You can also call the [HTTP API](/api-reference/introduction) directly. For a first end-to-end request, follow the
[quickstart](/quickstart).
